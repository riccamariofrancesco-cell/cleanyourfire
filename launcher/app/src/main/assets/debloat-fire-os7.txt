# CleanYourFire: lista di pulizia per Fire TV Stick con Fire OS 7.7.1.7 (build PS7717/5741, Android 9 / API 28).
# Base: examples/amazon-fire-tv-stick-lite-2020/debloat.txt di CleanYourTV (MIT, https://github.com/Gathin23/cleanyourtv),
# verificata sulla stessa build. Unica fonte per l'app (CleanupActivity) e per tools/cleanyourfire.sh / .ps1.
#
# Formato: "## [id] Titolo (on|off)" apre una categoria; ogni riga successiva è un pacchetto, "#" commenta.
# Tutto viene DISATTIVATO per l'utente 0 (pm disable-user --user 0), mai disinstallato; pm enable lo riporta indietro.
#
# Protetti su questa build ("Cannot disable a protected package"), quindi esclusi:
#   com.amazon.minerva.client.api, com.amazon.device.logmanager, com.amazon.device.crashmanager, com.amazon.diode,
#   com.fireos.usagestats.proxy
# Tenuti apposta: com.amazon.tv.launcher (Home, protetto), com.amazon.tv.settings.*, com.amazon.venezia (Appstore),
#   com.amazon.tv.ime (tastiera), servizi telecomando/Bluetooth, aggiornamenti OTA, ricerca vocale (com.amazon.vizzini,
#   aria, cardinal, ivona TTS, tcomm), Prime Video (com.amazon.firebat, com.amazon.tv.support), casting (cast.sink,
#   dialservice, awvflingreceiver, whisperplay, whisperlink), profili (com.amazon.prism.android.service),
#   com.amazon.tv.oobe (serve per il ripristino di fabbrica), salvaschermo, accessibilità (com.amazon.logan).
